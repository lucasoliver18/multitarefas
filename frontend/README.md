# MultiTarefas — Frontend

PWA mobile-first em React para o sistema de gestão de serviços da INFOOSEG
Sistemas de Segurança e Informática.

## Stack

- React 19 + Vite
- Tailwind CSS
- Axios (consumo da API REST do backend)

## Como iniciar

```bash
npm install
npm run dev
```

## Testes e build

```bash
npm run test
npm run lint
npm run build
```
